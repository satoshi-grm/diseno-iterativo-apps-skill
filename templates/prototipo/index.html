Flujos para recorrer

  1. FL-01 Cargar un turno: Inicio → Nuevo turno → completar → Guardar → aparece en Turnos.
  2. FL-02 Confirmar un pendiente: Turnos → filtro «Pendiente» → abrir → Confirmar.
  3. FL-03 Cancelar y deshacer: Detalle → Cancelar turno → Deshacer.
  4. FL-04 Lista vacía: Turnos sin datos.
